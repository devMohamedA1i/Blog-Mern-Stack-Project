# Full-Stack MERN Blog Platform

A full-stack blogging application built with MongoDB, Express, React, Node.js, and Redux Toolkit supporting authentication, post publishing, and management.

## Tech Stack

- JavaScript, Redux Toolkit, Axios, React, React Router, bcrypt, Express, JWT, MongoDB, MongoDB (Mongoose), Nodemailer, Node.js

## Structure

```text
├── backend/
├── frontend/
```

## Getting Started

```bash
git clone https://github.com/devMohamedA1i/Blog-Mern-Stack-Project.git
cd Blog-Mern-Stack-Project
# In frontend/
cd frontend && npm install && npm run start
# In backend/
cd backend && npm install && npm run dev
```
